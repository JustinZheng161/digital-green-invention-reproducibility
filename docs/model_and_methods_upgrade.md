# 模型与方法升级说明

## 审稿判断

本稿属于**企业层面观察性面板研究**，并非机器学习竞赛任务。因而“模型性能”不应以单一SOTA分数衡量，而应以样本匹配的可复现性、结局变量定义、固定效应结构、零值处理、时间顺序与推断边界共同评价。公开数据复现表明，论文描述的匹配规模、DT分布和零值比例可复现，但若干回归系数不能在缺少原始分析脚本的情况下精确对齐。修订稿不能继续把现有回归表表述为已经完全可复现的既定事实。

| 优先级 | 性能/科学瓶颈 | 实测或文本证据 | 已实施的修复 | 仍不可解决的边界 |
|---|---|---|---|---|
| P0 | **“绿色创新质量”测量构念不足** | 因变量为“当年联合申请的绿色发明数量”的对数；数据不含授权、引文、原创性或权利要求信息。 | 将结果定义改为“联合申请绿色发明专利产出代理”，并新增绿色实用新型替代结局；文献对比明确区分合作形式与质量。 | 无法从现有数据推导专利价值或创新质量；必须用CNRDS/INCOPAT等带授权与引文记录的可审计数据重建。 |
| P0 | **计数零值与线性模型不匹配** | 6,574个匹配观察中80.2251%绿色发明计数为零；DT高度右偏。 | 保留双向FE线性基准，同时估计企业与年份FE的条件PPML，并并列报告`ln(1+DT)`和1%/99%缩尾敏感性。 | 条件PPML不使用全零结果企业（当前N=2,774）；不能把它与OLS的N=6,443直接等同。 |
| P1 | **时间顺序、样本选择和因果识别不足** | 原始稿将前一观察值作为“1年滞后”会在不平衡面板中跨越年份；样本是两个异构数据集的交集，且D1发布日期为2025-09-11。 | 严格限制`t−1`和`t+1`为相邻日历年；完成未来DT安慰剂与分期检验；在文稿中删除因果用语。 | 没有可信外生冲击、原始政策处理定义、平行趋势或有效工具变量，不能报告因果效应。 |

## 已实现的两项核心优化补丁

### 补丁A：从年固定效应计数模型升级为企业—年份固定效应PPML

**替换/新增文件：** 新增 `run_analysis.py`；原稿中“因内存限制只含年份固定效应的Poisson/NB”说明被取代。该改动将计数模型从跨企业比较推进到控制企业不随时间变化特质的条件估计，并处理零计数。其方法依据是PPML对零值的自然处理以及多维固定效应算法 [1] [2]。

```diff
- # 旧实现：年份固定效应，Poisson/NB；不能控制企业固定异质性
- formula = "green_invention_count ~ log_dt + controls + C(year)"
- poisson = smf.glm(formula, family=sm.families.Poisson()).fit()
+ # 新实现：条件PPML，企业与年份固定效应，企业聚类CRV1标准误
+ formula = "green_invention_count ~ log_dt + controls | firm_id + year"
+ ppml_fe = pf.fepois(formula, data=panel, vcov={"CRV1": "firm_id"})
+ # 报告估计器实际使用N；全期结果为零的企业不识别条件企业效应。
```

复现值为 `β=0.093325`、企业聚类标准误 `0.050678`、`p=0.0655`、估计器N=`2,774`。该结果与只含年份固定效应的Poisson估计不是同一参数；修订稿只将其作为分布敏感性证据。

### 补丁B：对右偏DT和不平衡面板执行明确的变换与严格日历滞后

**替换/新增文件：** 新增 `run_specification_sensitivity.py` 与 `run_robustness_tests.py`；更新 `run_analysis.py`。DT原始值1%/99%分位数为0/134。该补丁将原始DT、缩尾原始DT、`ln(1+DT)`、`ln(1+缩尾DT)`、完整/核心控制集、当前/严格滞后暴露并列报告，防止由一个处理选择驱动结论。对数线性OLS在异方差下可能与PPML产生不同的弹性估计，支持并列报告而非择优报告 [2]。

```diff
- # 旧实现：上一条企业记录被当作“一年滞后”，即使中间年份缺失
- panel["log_dt_lag1"] = panel.groupby("firm_id")["log_dt"].shift(1)
+ # 新实现：只接受相邻日历年度的滞后值
+ panel["log_dt_lag1"] = panel.groupby("firm_id")["log_dt"].shift(1)
+ panel["previous_year"] = panel.groupby("firm_id")["year"].shift(1)
+ panel.loc[panel["year"] - panel["previous_year"] != 1, "log_dt_lag1"] = np.nan
+
+ # 显式处理右偏DT，不改写原始变量
+ q01, q99 = panel["dt_raw"].quantile([0.01, 0.99])
+ panel["dt_winsor_1_99"] = panel["dt_raw"].clip(q01, q99)
+ panel["log_dt_winsor_1_99"] = np.log1p(panel["dt_winsor_1_99"])
```

## 实际规格敏感性结果

| 规格 | β | Firm-clustered SE | p值 | 估计器N | 含义 |
|---|---:|---:|---:|---:|---|
| 原始DT，双向FE、对数专利结果、完整控制 | 0.000832 | 0.000636 | 0.1911 | 6,443 | 原始线性尺度下不显著。 |
| `ln(1+DT)`，双向FE、对数专利结果、完整控制 | 0.019628 | 0.010161 | 0.0536 | 6,443 | 边际显著，95%CI跨零；不宜作为稳健正向发现。 |
| `ln(1+缩尾DT)`，双向FE、对数专利结果、完整控制 | 0.019482 | 0.010198 | 0.0563 | 6,443 | 与未缩尾的变换结果接近。 |
| `ln(1+缩尾DT)`，双向FE、对数专利结果、核心控制 | 0.020346 | 0.010157 | 0.0454 | 6,443 | 对控制集有敏感性；不能据此择优。 |
| `ln(1+缩尾DT)`，PPML双向FE、发明计数 | 0.093206 | 0.050840 | 0.0668 | 2,774 | 计数链接中边际显著，且有效样本发生选择。 |
| 严格日历年` t−1 `，PPML双向FE | 0.052899 | 0.059118 | 0.3709 | 1,891 | 缺少短期滞后关联证据。 |
| 严格日历年` t+1 `，PPML双向FE安慰剂 | 0.091010 | 0.058989 | 0.1229 | 1,742 | 未达常规显著性，但不构成反向因果排除证明。 |

这些估计反映了已声明样本和规格下的关联。主文将把总体结论收窄为：**数字化转型与联合申请绿色发明产出的关联对函数形式、控制集和条件PPML有效样本敏感，现有证据不足以支持稳定的质量提升或因果主张。**

## 与文献比较时必须固定的三项条件

| 必须固定的条件 | 当前建议值/规则 | 原因 |
|---|---|---|
| 样本宇宙与年份 | 中国A股非金融企业；2014–2020；将原始合并样本N=6,574、估计器N和删除规则分别报告。 | 保证与数据DOI一致，避免用不同年份或可得性筛选制造“提升”。 |
| 数字化转型处理 | 主报告`ln(1+DT)`，并在附录报告原始DT及1%/99%缩尾DT；不允许只报告最显著规格。 | 原始DT为强右偏，函数形式实质影响系数与p值。 |
| 固定效应/推断 | 企业和年份固定效应；标准误按企业CRV1聚类；PPML必须单列有效N及全零企业删除规则。 | 使模型基于企业内部变化，且不把年FE计数模型冒充为双向FE稳健性。 |

## 两个更适合最终论文的权威数据方向

| 数据方向 | 适配理由 | 公开/许可注意事项 |
|---|---|---|
| **CNRDS绿色专利微观记录 + CSMAR/WIND财务和治理数据** | 可重建统一的公司—年度宇宙，并将申请、授权、被引、技术分类、联合申请与非联合申请拆分，解决当前“质量”代理与异构拼接的根本问题。 | 典型为机构订阅数据库；只在获得有效授权后使用。禁止把受限记录上传到公开仓库。 |
| **INCOPAT或IncoPat全球专利数据库 + 上市公司年报文本语料** | 支持专利家族、前向被引、权利要求、同族规模等质量代理；直接从年报文本构建DT，避免二次数据集的定义漂移。 | 许可可能限制原始记录再分发；公开仓库应保留抓取词典、代码和不可逆汇总，而非数据本体。 |
